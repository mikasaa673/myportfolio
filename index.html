Talk2Fill: Simplifying Banking

Talk2Fill is a voice-based form-filling web application that simplifies data entry using speech recognition. Built with HTML, CSS, and JavaScript, it allows users to fill out forms hands-free by speaking their responses. It supports multiple input fields like name, email, and address with real-time voice-to-text conversion. The project enhances accessibility and provides a faster, more intuitive way to complete forms.

YouTube Audio Downloader

YouTube Audio Downloader is a Flask-based web app that lets users download YouTube videos as high-quality MP3 files. Built with Flask and yt-dlp, it features a modern, responsive interface with dark/light mode support. The app ensures fast downloads, automatic file organization, and smooth performance for a seamless user experience.
